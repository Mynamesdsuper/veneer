# Bundled themes

Themes shipped with Veneer. Each theme lives in its own folder with a `theme.json`, an `assets/`
folder and a `LICENSE` or `CREDITS` file.

Planned for the first release:

- `aqua-like`: a top menu bar and a bottom dock, with original artwork.
- `strip`: a single bar at the bottom with apps, clock and status, and no dock.

Only original assets, or assets with a compatible and declared license, may be added here.

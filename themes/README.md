# Bundled themes

Themes shipped with Veneer. Each theme lives in its own folder with a `theme.json`, an `assets/`
folder and a `LICENSE` or `CREDITS` file.

Only original assets, or assets with a compatible and declared license, may be added here.

| Theme | Layout | Notes |
|-------|--------|-------|
| [`aqua`](aqua) | Glass menu bar on top, magnifying dock at the bottom | The default theme. Light and dark. Artwork generated by `tools/theme-art/make-art.ps1`. |
| [`strip`](strip) | One floating bar at the bottom: menu, pinned and running apps, status and clock; no dock | Light and dark. Artwork generated by `tools/theme-art/make-art.ps1 -Theme strip`. |

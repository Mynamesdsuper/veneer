# Strip: credits

All artwork in this theme (wallpapers and logo) is original. It is generated by
`tools/theme-art/make-art.ps1 -Theme strip` from gradients and shapes, and released under the same MIT license as
Veneer.

App icons come from Windows (or from the apps themselves) at run time, and status icons from Windows' own Segoe
Fluent Icons font; none of them are shipped with the theme.
